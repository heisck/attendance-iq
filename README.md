# Base Agent Rules

Project-agnostic rules for AI coding assistants. Copy into a new project so the agent starts with the same standards.

| File | Role |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Short rules the agent reads every run |
| [`docs/base-rules.md`](docs/base-rules.md) | Full detail: kickoff checklist, design, security by feature, engineering, review, done |

## Use in a new project
1. Copy `AGENTS.md` and `docs/` (keep the project's own README).
2. Append a project section to `AGENTS.md`.
3. Keep project-specific detail out of the base rules.

If the files disagree, `AGENTS.md` wins.
